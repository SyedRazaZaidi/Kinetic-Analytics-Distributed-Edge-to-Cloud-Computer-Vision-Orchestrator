## 🚀 About Kinetic Analytics
Kinetic Analytics is a high-performance, edge-to-cloud computer vision orchestrator designed for real-time spatial intelligence and safety monitoring. Built entirely on a decoupled local architecture, it bypasses costly cloud hosting while delivering enterprise-tier telemetry, automated agentic logging, and business intelligence integration.

### Core Architecture & Features
* **Zero-Latency Ingestion:** Asynchronous ZeroMQ message brokering streaming raw sensor frames from edge nodes to the FastAPI Cloud Brain.
* **Dual-Engine Vision Fusion:** Simultaneous real-time 17-point COCO skeletal pose tracking (`YOLOv8n-Pose`) and multi-class object detection (`YOLOv8n`) using BoT-SORT object permanence.
* **Heuristic & Synergy Engine:** Mathematical action recognition (raised hand detection) and axis-aligned bounding box (AABB) intersection math to track human-object tool usage.
* **Kinematic Fall Detection:** Automated spatial ratio analysis to instantly catch structural collapses and log emergency safety alerts.
* **Time-Series Intelligence:** Built-in SQLite event logging engine featuring live terminal streaming and a normalized CSV export pipeline for Power BI analytics.
